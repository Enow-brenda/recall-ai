# Recall Product Specification

## Project Overview
**Recall** is a chat-based memory layer for your inbox. It allows users to ask plain English questions about their emails and attachments and get instant answers with cited sources.

## Brand Identity
- **Vibe:** "Intelligent Memory," "Ambient AI," "Effortless Retrieval."
- **Aesthetic:** Minimalist, text-forward, high contrast.
- **Colors:** Deep Indigo/Slate (#0F172A), Sunset Orange (#EA580C).

## Core Features
1. **Conversational Search:** Ask questions about email content.
2. **Document Memory:** Search inside attachments.
3. **Actionable Calendar:** Convert meeting mentions into calendar events.
4. **Source Transparency:** Every answer cited with expandable source chips.

## User Journey
1. **Landing Page:** Value prop and "Connect Gmail" CTA.
2. **Empty State:** Indexing phase after first login.
3. **Active Chat:** Conversational retrieval with sources.
4. **Action State:** Calendar integration and snippet previews.
5. **Account Management:** Connecting multiple Gmail accounts, with Slack/WhatsApp coming soon.
